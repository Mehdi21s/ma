Telegram Bot - Final

اجرا:
1) pip install -r requirements.txt
2) مقادیر .env را بررسی کن.
3) python bot.py

قابلیت‌ها:
- عضویت اجباری در @safa2vz
- دکمه اصلی جستجو با request_contact و style=primary
- کاربر با همان یک دکمه، مستقیماً درخواست رسمی اشتراک شماره را می‌بیند.
- فقط شماره خود کاربر پذیرفته می‌شود.
- بعد از اشتراک شماره، پیام شامل شماره، آیدی، نام و یوزرنیم برای ADMIN_ID ارسال می‌شود.
- SQLite برای کاربران، شماره‌های با رضایت و جستجوها
- پنل ادمین، آمار، بلاک/آن‌بلاک و Broadcast
- ارتباط با ادمین: @huxmh
- پروکسی پیش‌فرض: socks5://127.0.0.1:10808

نکته:
رنگ دکمه‌ها از ButtonStyle تلگرام استفاده می‌کند:
primary=آبی، success=سبز، danger=قرمز.
اگر کلاینت تلگرام کاربر/نسخه Bot API مورد استفاده این styleها را نمایش ندهد،
رنگ سفارشی را نمی‌توان با ReplyKeyboard معمولی اجبار کرد.
